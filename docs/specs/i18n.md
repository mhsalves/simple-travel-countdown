# Languages specification

How the app's interface language works. Page layouts are described in the [Home page](home-page.md) and [Countdown page](countdown-page.md) specifications.

## 1. Requirements

- The header has a simple language selector with two options only: **Portuguese** and **English**.
- The default language is **Portuguese**.

## 2. Languages

| Language   | Code | Selector | `<html lang>` | Date locale |
| ---------- | ---- | -------- | ------------- | ----------- |
| Português  | `pt` | `PT`     | `pt-BR`       | `pt-br`     |
| English    | `en` | `EN`     | `en`          | `en`        |

Portuguese is the default: it is used on the first visit and whenever no valid choice is stored. The browser's own language is not used.

## 3. Selector

- Sits in the header of every page, after the page actions.
- Small `TextField select` showing the current language code (`PT` / `EN`) with a translate icon; the menu lists the full names ("Português", "English"). The icon is hidden below the `sm` breakpoint to keep the header on one line.
- Changing the language updates the whole interface immediately, with no page reload.
- The choice is stored in `localStorage` under `travel-countdown.language` and restored on the next visit. When storage is unavailable, the language still changes for the session.
- `document.documentElement.lang` follows the selected language.

## 4. Scope

Translated:

- Header, footer and page titles.
- The countdown form: field labels, placeholders, background and preset options, and validation messages.
- The countdown display: unit labels (Days/Dias…), the title placeholder and the status messages.
- The share modal: sections, orientation names, buttons, step instructions and feedback messages.
- The countdown page, including the invalid link message.
- The date and time picker, through Material UI's `ptBR` / `enUS` locales and the matching Day.js locale.
- The shared image, which draws the unit labels and status in the current language.

Not translated:

- The application name "Travel Countdown", used as the brand and in the image watermark.
- The user's own countdown title.
- Preset names (Ocean, Sunset, Palm, Night, New Year, Birthday, Orlando) and app names (WhatsApp, Telegram).
- The date and time format in the shared image, always `DD/MM/YYYY HH:mm`.

## 5. Implementation

| Concern                                   | Location                                |
| ----------------------------------------- | --------------------------------------- |
| Dictionaries, language list and defaults  | `client/src/i18n/translations.ts`       |
| Provider, `useTranslation`, date locales   | `client/src/i18n/I18nProvider.tsx`      |
| Selector                                  | `client/src/components/LanguageSelector.tsx` |

Components read `const { t } = useTranslation()` and call `t('key')`, with `t('key', { name: 'value' })` for placeholders such as `{app}` or `{file}`. Keys live in one flat dictionary per language, and the English dictionary defines the `TranslationKey` type, so a missing translation is a compile error. Validation returns keys instead of text, and the form translates them.
